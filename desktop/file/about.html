说明

Guide

游玩须知
  • 推荐使用电脑游玩，分辨率不低于 1920×1080
  • 游戏包含音乐与音效，建议佩戴耳机体验
  • 含屏幕闪烁、乱码等视觉特效，光敏性癫痫患者请勿游玩
游戏玩法

这是一款以「调查」为核心的网页解谜游戏。你将利用桌面、邮箱、搜索引擎等工具搜集线索，通过推理、解谜、输入密码推进剧情，解锁不同结局。

解谜时请仔细阅读文本、善用搜索功能、留意可交互元素，线索多藏于细节处。

注意：所有线索均在游戏页面内，无需查看网页源代码。

辅助工具
  • 备忘录 桌面右上角实时同步调查进度
  • 记事本 桌面内置记事本，可记录关键线索，内容自动保存
  • 通知系统 进度更新时，桌面右下角弹出提示
  • 成就系统 位于「开始菜单」，记录你的完整游戏历程
存档与重启
  • 游戏进度自动保存至浏览器本地，清理浏览器缓存将丢失存档。
  • 可通过「开始菜单」→「重新开始」重置全部进度，操作不可恢复。
